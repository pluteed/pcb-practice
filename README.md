## 踩坑记录

- **封装引用 bug（已修复）**：早期版本里 15 处元件的封装被写成"名称字符串"（如 `C0805`、`LQFP-44_...`、`HDR-TH_4P-P2.54-V-M`），而非指向封装库的 uuid，嘉立创EDA 解析不了会报"封装缺失 / 无效"。修复后源文件内 **0 个非法封装引用**，且导出的 Gerber 渲染出 608 个焊盘，反向证明封装全部正确绑定。
- **教训**：元件的封装走的是 `组件 → DeviceName(uuid) → DEVICE 器件文档 → 器件内嵌封装` 这条链，不是组件自身 `Footprint` 属性；改工程 JSON 时只能动结构性字段，且每次先备份。

2. **最小间距 / 丝印压焊盘 / 锐角**：用嘉立创免费 DFM 工具复核一遍最稳。
